## The CISM mindset

- Think like an **information security manager advising the business.**
- Security exists to **support business objectives.**
- **Business owners and senior management** make risk decisions; the security manager advises and facilitates.
- Prefer **governance, strategy and process** answers over jumping to technical fixes.
